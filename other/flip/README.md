# flip

Flip a coin once or multiple times with statistics.

## Usage

```bash
flip                    # single flip
flip [number_of_flips]  # multiple flips
```

## Installation

To install the script to `$HOME/bin`:

```bash
curl -o ~/bin/flip https://raw.githubusercontent.com/KennedyIDK/bash-scripts/main/other/flip/flip && chmod u+x ~/bin/flip
```
